# CST Delta Volume

通过 CST MCP 读取选面，在副本上得到目标几何，再生成增料体和减料体，将编辑写回原实体。
默认使用 SAT/BRep 数据分析与数值验证；不依赖 computer-use、截图或人工辨认模型位置。

## 入口与范围

- 先读仓库根目录的 `AGENTS.md`；改服务器、桥或原生代码前再读 `docs/DEVELOPING.md`。
- 在用户正在操作的 CST 项目上工作：`cstmcp.py up` 复用现有栈，按 DE PID 附着。
  不要为读取用户选面另开一个空的隔离栈。独立实验才使用隔离栈。
- 读取 `cst_status`、`cst_get_selection`，确认活动项目、目标 solid、原生 face ID。
  `cstFaceId` 不等于 ACIS 枚举下标，也不等于 BRep 不透明 ID。
- 用户说选了两个面而接口只读到一个时，先请其补选或明确只改当前面，并继续只读备份/分析。
  收到“补选”后仍须重新读取实际选择；不能把旧 ID、另一半圆柱面或等待时长当成第二个拾取面。
- 缺少方向、距离或单位时，只询问这些必要信息。用户已经指定操作时继续执行；
  不为生成副本、局部 delta、验证或已授权的应用重复请求确认。
- 需要补选面时，根据邻接和几何连续性确定范围，并说明原因。
  用户没有授权扩大范围且补选会明显改变另一特征时，保留已有工作并澄清范围。

## 工作流

具体命令与 CST 宏写法见 [references/workflow.md](references/workflow.md)。
孔特征的内核错误与解析体路线见 [references/analytic-holes.md](references/analytic-holes.md)。

1. **保留编辑前状态。** 记录项目路径、DE/modeler PID、目标名称、材质、几何单位、
   选面及本次位移。仅导出目标实体的 `original.sat`，并记录体积与必要的拓扑数据。
   用 SAT/BRep 分析所选面的支撑曲面和邻接。仅需要局部显示或采样时才导出面三角网格。
2. **在临时副本上形成目标。** 使用一次多面 `LocalModification.MoveSelectedFaces` 或
   `OffsetSelectedFaces`，不要逐面修改后沿用旧 ID。使用全局向量时切换到全局 WCS，
   并保留原坐标系状态。导出 `modified.sat`；检查位移、曲率参数和邻接闭合是否符合意图。
   若完整孔壁/倒角在副本上移动失败，保留错误并检查实际交叉。
   可以从实测曲面重建原孔空域 H0、新孔刀具体 H1，以 `T = (original ∪ H0) − H1` 构造目标；
   这条路线须核实旧孔填充范围、新孔端部余量与外壁贯通，不能泛化为任意失败面的修复。
3. **求局部增减料体。** 选取包住整个变化区域的轴对齐盒子 R，含原、新位置和被延伸/裁剪的邻面。
   确认盒外几何未变，并给盒边界留出避开变化区域的余量。
   令 A = 原体 ∩ R、B = 目标体 ∩ R，计算 `remove = A − B`、`add = B − A`。
   空体按 `faces=0` 判断，不导出成待导入 SAT。
   若上述孔路线在相近实体求差时仍报 `BAD_CONTAINMENT`，可改算
   `remove = original ∩ H1`、`add = H0 − H1`，再验证回放等于 T。
4. **回放验证。** 在另一份原体副本上执行 `(original − remove) ∪ add`，按非空分支处理。
   同时检查目标特征的几何、闭合性、delta 的空间范围、体积关系及盒外区域。
   核对 `V_after ≈ V_before − V_remove + V_add`，以 CST 实测体积为准。
   复杂曲面的积分误差须与参数、边界及采样一起判断，不能为通过检查反复放宽体积阈值。
5. **写入原实体。** 在最终应用前重新确认活动项目、目标及编辑前几何没有变化。
   清理本次临时实体。把已验证 delta 的 SAT 导入及布尔操作合成一个 `cst_vba` 历史块；
   历史不能引用仅由临时控制宏创建的 scratch 实体。重新导出最终实体，核对实测结果，
   再按几何重新定位、高亮修改后的面。

## 本仓库的脚本

- `scripts/control.py`：用 CST 自带 Python 3.6 执行带项目路径守卫、超时和 BEGIN/END 回传的
  临时控制宏。每次输出写入新的 JSON；自动保留 quiet 状态。用于查询和本次 scratch，
  正式应用仍走 `cst_vba` 历史。
- `scripts/local_delta.py`：原体/目标体经局部裁剪后双向求差。
- `scripts/void_delta.py`：从实测的原孔空域、新孔刀具体直接求两种布尔工具，跳过相近实体求差。
  前提、命令和验证要求见解析孔参考。
- `scripts/topology.py`：区分正常配对边、已确认的零长度锥尖退化边与未解释的开边；
  `boundary_report(Model(...))` 是边界检查，不代替完整实体有效性检查。

`scripts/local_delta.py` 在指定 modeler 的 **ACIS 脱离项目的临时体** 上计算两种 delta，
不会将结果导入 CST 或编辑项目历史。它不自动选择面、创建目标体、证明区域覆盖或应用编辑。
先完成上述第 1、2 步，再使用它。

从仓库根目录执行，下例坐标和 PID 必须换成本次实际值：

```powershell
py -3.12 .agents/skills/cst-delta-volume/scripts/local_delta.py `
  --modeler-pid <modeler> --original <original.sat> --modified <modified.sat> `
  --bounds <xmin> <ymin> <zmin> <xmax> <ymax> <zmax> --out <new-output-dir> --dry-run
```

核对计划后去掉 `--dry-run` 执行。输出 `original_local.sat`、`modified_local.sat`、
非空的 `remove.sat` / `add.sat`，以及 `manifest.json`（命令、空体标记、近似质量属性）。
输出目录必须是新的；当前原生命令要求使用无空白、ASCII 的几何文件路径。

原生管道一次只服务一个客户端。服务器已经 `acis_connect` 时，不要再抢同一根管道。
确认没有其他调用者或进行中的操作，暂时停止对应 owner（**不带 `--with-cst`**），
执行脚本后用原 DE/modeler PID 和端口恢复 owner，重新连接 CST 与 ACIS。
若栈正由其他任务使用，先协调使用时段，不能直接停掉它。

若执行器沙箱看不到 CST 进程或拒绝命名管道，而固定 HTTP owner 的 `cst_status` 正常，
保留宿主 owner，走 MCP 的 CST 建模接口；不要在沙箱里停掉后重建一个无法连接 CST 的 owner。
隔离回归可通过 `cst_vba` 实现查询、Brick 裁剪和 Solid 布尔，详见工作流中的沙箱分支。

## 验证与故障边界

- 工具返回成功或 `applied_to: modeler` 不等于几何已生效。最终必须重新测量、导出并核对。
- 不把面数保持、某个 ID 保持或本次案例的数值当作所有编辑的硬要求。
  布尔操作可能重编号；核对支撑曲面及边界后才使用新 ID。
  两个半圆柱面可以合并成一个完整圆柱面，圆角和锥槽也可以合并面。
  以移动后的特征重新高亮，不能为了凑原来的面数沿用旧 ID。
- 比较圆柱时检查轴线、半径、裁剪范围；比较平面时检查法向与平面方程。
  同一支撑曲面的参数原点可以改变，不能只比较原点坐标。
- 只比较顶点或总体积不能证明整个模型等价。还需检查变化曲面/边界，必要时做区域采样或差集验证。
- 复杂整件求差可能遇到 `MISSING_SPAN_INFO`。优先改用局部裁剪后求差；
  不在用户原体上反复重试失败布尔操作。局部求差失败时停止应用，保留导出与日志，
  根据具体几何检查区域边界或切换已满足前提的解析孔路线。
  未识别的几何、无法确认的旧空域或解析路线再次失败时，保留进度并报告具体阻碍。
- 脚本超时仅表示客户端停止等待，原生调用可能仍在运行。确认 CST 已恢复可用后再操作。
  不以重启 modeler 来掩盖错误或丢弃用户未保存的项目。
- 不把未知 VBA API 的试错写进最终历史。控制宏可用于查询和临时副本；
  历史失败后不要继续盲目追加命令。保留 SAT 回退材料，不擅自覆盖整个原项目。

## 交付

简述编辑方向/距离、实际包含的面、增减料体积与验证结果；提供原体、delta、最终模型的路径。
保留最终历史所依赖的 delta SAT。当前模型已修改、导出 SAT、保存整个 `.cst` 是不同状态，
按实际完成的内容汇报。不要把调试过程或所有几何数据堆进最终回复。
