# cnc-bottom.sat 特征树反求与重建 —— 结果与限制

日期：2026-10-30。输入：`models/cnc-bottom.sat`（1 个体，1402 面，86.2 × 20.2 × 7.5 mm，CNC 结构件）。
代码在 `tools/feat/`，ACIS 侧命令在 `native/agent_ops.inc`（agent21）。所有中间产物在 `out/`（不入库）。

## 1. 结论

| 问题 | 结论 |
|---|---|
| 能否得到特征树 | 能。2.5D 分层分解给出"基体 + 凹槽/孔"的树，并能逐个记录圆角、倒角、拔模及其参数 |
| 按树重建的整体形状 | 对。CST 重建体积与原件差 −0.55%，凹槽、开窗、通孔位置都在 |
| 圆角、斜面能否还原 | **大部分不能**。拔模可以可靠重放；圆角/倒角用 ACIS 等半径倒角重放成功率约 1/4（见 §5） |
| 可编辑性 | 棱柱特征（轮廓 + 深度）可编辑；圆角半径、倒角宽度、拔模角已作为参数记录，但重放不可靠 |

## 2. 方法

1. **SAT 直接解析**（`sat.py`）：读拓扑与解析曲面（平面/圆柱/圆锥/环/球），样条边用 NURBS 求值。
2. **面分类**（`classify.py`）：相对 Z 轴分为朝上底面、朝下顶面、竖直壁、其它；面朝向用环的有向投影面积判定（= ∫n_z dA），对全部水平面验证无误。
3. **分层分解**（`tree.py`）：每条竖直线穿过零件只有一段材料（实测重叠 < 0.7%），因此
   `零件 = 基体(外轮廓, z_bot..z_top) − Σ 顶面凹槽(水平集 {t ≤ L}) − Σ 底面凹槽({b ≥ L})`，嵌套关系由包含关系给出。
4. **去特征**（`defeature.py`，在 CST 的 modeler 里调 ACIS）：逐链 `api_remove_faces` 删圆角/倒角，`api_taper_faces` 把拔模壁转回竖直；每步记录参数与新尖边位置，并用包围盒 + 体积校验，越界就撤销（`snap`/`undo`/`mass`）。多轮迭代直到无进展。
5. **重放**：CST VBA（`rebuild_cst.py`，折线轮廓）或 ACIS（`replay_acis.py`，真圆弧轮廓 + 反向重放拔模/倒角/圆角）。

## 5. 限制与原因

1. **圆角重放**：`api_blend_edges` 只做等半径边圆角。原件中的角部顶点过渡（球面、样条补片）、变半径链、被拆成单面删除的链，都无法用它还原；一步失败后，后续操作的边对不上，连锁失败（"no matching entities" 占圆角失败的一半）。
2. **拔模去不掉**：拔模壁根部留有删不掉的圆角时，`api_taper_faces` 报 `LOP_TWK_NO_VERT`；346 个拔模面只回正 50 个。剩余拔模面在棱柱树里被近似成台阶，导致棱柱基体与去特征体不一致。
3. **ACIS 棱柱布尔不稳**：近重合面导致 53/249 次布尔失败；CST 侧靠"失败则收缩 0.2 / 1 µm 重试"达到 206/208。
4. **轮廓**：投影后的椭圆/样条边界只能拟合成短直线（v2 仍有 7674 段直线、4359 段圆弧）；`parcur` 交线只存参数域曲线，未实现曲面求值，按弦处理。
5. **侧向特征**：只分解了 Z 向；±Y 方向加工的边沿缺口没有单独识别。

## 6. 可继续的方向

- 圆角重放：每步按记录几何校验、失败回滚；边按点到边距离匹配而非包围盒；整链（含顶点过渡）一起倒圆角。
- 先解决拔模（拔模层已证明可重放），让棱柱基体与去特征体一致，再上圆角。
- 精度比对改为 Python 侧按特征树判定重建体的点，避免在大 SAT 上跑 `api_point_in_body`。

## 7. 试验：按加工工序重建（刀具扫掠体）

思路：零件是 CNC 加工的，凹圆角、竖直内角、拔模壁都是刀具形状留下的。把每个槽看成一道工序
（平底区域 Fl、刀尖圆角 r、锥度 a），刀具扫过的体积 T 单独建好再从毛坯里减掉；
圆角不再在整个零件上倒，而是在只有十几个面的 T 上倒。

### 7.1 依据

| 统计项 | 凹面，刀具留下的（个） | 凸面，修边（个） |
|---|---|---|
| 圆柱圆角（轴不沿 Z） | 233 | 165 |
| 竖直圆柱壁 | 66 | 22 |

判据：通孔圆柱面的朝向。凹圆角半径和拔模角都落在少数几个离散值上（§3.3），与刀具库一致。

### 7.2 识别（`tools/feat/machining.py`，纯 Python）

在 (s, h) 半平面里，刀具模型的截面是：底面 → 半径 r 的圆弧 → 按 a 外倾的直线壁
（s = 到 Fl 边界的平面距离，h = 高出槽底的高度）。对每个槽，从刀具库里拟合 (r, a)，
再统计原件中落在模型壁内侧的面，有多少个在 2 µm 以内被模型解释。

| 统计项 | 数值 |
|---|---|
| 识别出的槽（个，顶面 + 底面） | 96 |
| 落在模型范围内的原件面（个） | 347 |
| 其中被刀具模型在 2 µm 内解释的面（个） | 202 |

底面一侧的大区域（底板以下 −0.16 … −2.97 mm 的各层）几乎解释不了：那里是斜面和样条面，属于
三维曲面加工，不是 2.5D 槽。斜面（302 个）、样条（229 个）、凸修边圆角（165 个）都不在槽模型内。

### 7.3 ACIS 建刀具体并比对（`tools/feat/tool_pockets.py`，agent25）

对每个槽：
1. T = 壁轮廓（Fl 外偏 r）棱柱，从槽底到槽口以上 0.3 mm，底边倒 r。圆角只在这个孤立棱柱上倒。
2. K = 探测薄板：轮廓内缩 1 µm，从槽底以上 1 µm 到槽口以下 1 µm。K 不和槽的任何面重合，所以布尔稳定。
3. 比较 vol(原件 ∩ K)（原件留在槽里的圆角材料）和 vol(K − T)（刀具留下的材料）。

|---|---|---|---|---|---|---|---|---|---|---|

| top18 / top19 | 0.94 | 0.1123 | 0 | 0.95 | 是 | +0.0001 | 0.0096 | 0.0179 | +0.0084 | 1.2 |
| top22 | 1.38 | 0.1123 | 0 | 0.84 | 是 | −0.0028 | 0.0098 | 0.0174 | +0.0076 | 1.3 |
| top23 | 1.11 | 0.1123 | 0 | 0.84 | 是 | −0.0003 | 0.0099 | 0.0182 | +0.0084 | 1.4 |
| top24 / 25 / 26 | 0.92–0.94 | 0.1123 | 0 | 0.84 | 是 | +0.0001 | 0.0096 | 0.0179 | +0.0084 | 1.4 |

### 7.4 结论

- **带拔模、带圆角的槽可以精确还原**：top9（5° 锥度刀，r = 0.2246 mm）的刀具体和原件只差 0.06 µm。
  原来"在整个零件上倒圆角 + 拔模"这条路，拔模和圆角正好是失败最多的两类。
- **刀具体在 13 个试验槽中建成 11 个**。小槽是球头刀角部（轮廓角半径 = r，精确倒圆角是退化环面），
  倒圆角半径要比 r 小 2 µm 才能成功；10 个可比的槽里，9 个偏差在 1.4 µm 以内（系统性偏多，
  量级与轮廓拟合容差 1–2 µm 一致）。
- **失败集中在轮廓质量**：大槽 top16 的轮廓有 115 段，其中有比 r 还短的弦（来自参数域交线按弦处理），
  倒圆角在这些短段处封口失败。这和 §5.4 是同一个根因。下一步要先把槽底边界还原成真圆弧/直线，
  而不是拟合折线。
- 比对用的布尔仍偶尔失败（top6）；这是验证手段的问题，不是重建本身的问题：真实重建是
  "毛坯 − T"，不存在 T 与已有圆角面重合。
- **覆盖面有限**：2.5D 槽模型只解释了 202 个面。斜面、样条区（底部三维曲面）和凸修边需要另外的工序模型：
  修边 = 倒角刀/R 角刀沿边扫掠；三维曲面 = 球头刀，或保留原件该区域的 B-rep。

代理新增命令（`native/agent_ops.inc`）：`swap`（主体/副体互换）、`bool add|cut|int`、
`offset <d> [vent]`（`api_offset_body`；平面会直接延伸、不产生滚球圆角，所以不能用来做刀具包络）。
